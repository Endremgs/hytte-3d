# Hellesmoveien 33 – 3D mulighetsstudie

Åpne `dist/hytte-tjome.html` i en nettleser (Chrome/Safari). Én fil, fungerer uten internett.

Bygg på nytt: `npm install && node build.mjs`. Data i `data/` er laget av `prep/prep.py`
fra Kartverket (DTM/DOM, matrikkel), OSM, Esri-flyfoto og arkitektens PDF-er (se docstring).
Lokalt koordinatsystem: origo i adressepunktet (UTM32 E 580152, N 6549299), x=øst, y=nord, NN2000.
